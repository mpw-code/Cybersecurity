## Types of Network

- LAN Local Area Network - Could be 2 or 1000 hosts in a building
- WAN Wide Area Network - Spans the globe
- MAN Metropolitan Area Network - Covers a city (smaller than WAN)
- CAN Campus Area Network - Multiple LANs
- SAN Storage Area Network - Storage servers with an HDD
- PAN Personal Area Network - Bluetooth between Airpods en phone

## Peer to Peer

- Peer to Peer is a decentralized network. Everybody is a server AND a client. (Bittorent, Napster, etc)
- Client Server network:multiple clients (computer, smartphones, etc.) connect to a central server to access shared resources.

Backbone = powerfull switch

Segments = smaller switch (for rooms). Is smaller.

Backbone = main infrastructure that interconnects various segments of a computer network. Designed for high speed data.

Topology = describes the layout or arrangement of elements (links, nodes etc) of a computernetwork. (2 machines directly use crossover cable)

Mesh = each host is connected to the other host.
